### Paper behavior to preserve

- Text remains ordinary DOM content. Editing uses a real contenteditable document aligned to the rendered node, while canvas chrome renders the visible caret and selection.
- The stored text model distinguishes content from typography and sizing intent.
- Width and height support Fixed, Fit, Fill, and Relative where the parent can supply a reference.
- Fit width uses intrinsic no-wrap content. Fixed width wraps. Fit height grows to content. Fixed height keeps its authored bound and may clip or truncate only when explicitly configured.
- Typography covers family, style, weight, size, line height, letter spacing, horizontal alignment, vertical alignment, case, wrap mode, keep-words, truncation, and maximum lines.
- Existing files must migrate without an unrequested visual change.

- Enter and Shift+Enter both create line breaks in the plain-text schema.
- Every content transaction updates the live document during collaboration while one editing gesture remains one semantic undo entry.

### Resize

- Ordinary resize changes bounds without changing font size.
- Shift preserves aspect ratio. Alt resizes symmetrically. The primary modifier keeps content static for crop or reveal behavior and suppresses snapping where Paper does.
- Double-clicking a resize handle changes the affected axis to Fit. Alt-double-click changes it to Fill only when the parent can provide that axis.
- Resize uses rotation-aware local axes and preserves the visual handle under the pointer after handle crossing.
- Centered and right-aligned text compensate their anchor when width changes.

## Phase 3: flex conversion core

Readiness audit result: NO-GO on 2026-10-11. The current Flex implementation is a component-layout baseline. Canvas primitives cannot yet carry layout, participate in DOM Flex, or use the existing conversion commands. Phase 3 therefore starts with a stored-model and projection generalization, not with inspector controls.

Orchestrator decisions for the Phase 3 foundation:

- Store `freeform`, `flow`, and `absolute` as distinct placement modes. A missing primitive layout remains legacy `freeform`; a missing component layout remains `flow`.
- Roll the file schema to v9, preview envelope protocol to 6, and preview document version to 2. V8 to V9 is version-only for valid legacy documents and never materializes layout records.
- Keep primitive rotation, flips, clipping, and `TextSizing` as their existing single authorities. Primitive layout transforms and text layout width or height are invalid.
- A semantic flow or nontrivial absolute primitive without a current preview measurement has no exact interaction rectangle. Exact-geometry callers must omit or defer that interaction instead of fabricating one from stale stored coordinates.
- Phase 3 is primitive-layout parity only. Changing the existing component-slot child topology is a separate architecture change and will not be hidden inside this migration.

### Conversion

- `Shift+A` adds flex to a freeform frame or wraps an ordinary selection in flex.
- `Shift+Alt+A` removes flex.
- Remove flex produces freeform children at their measured world positions. It does not convert the parent to block.
- Add flex requires one shared parent and measures the union of each child's world AABB. For two or more children it divides center spread by union size on each axis; only a strictly larger normalized Y spread chooses column, so every tie chooses row. One wide child chooses column/start while a tall or square child chooses row/center.
- Row sorting uses only authored X; column sorting uses only authored Y. Stable ties keep the incoming tree order. Rotated-node direction still uses AABB centers even though sorting uses X or Y.
- Cross alignment compares the range of start edges, end edges, and centers. The smallest range wins with exact tie priority start, then end, then center. Add never infers stretch.
- Add uses the rounded mathematical median of adjacent measured edge gaps. Negative overlaps remain in the sample set before the final gap is clamped to zero. An even sample count averages its middle pair. A single child uses rounded main-axis padding as its gap.
- Direct Add derives non-root padding only from the rounded, nonnegative leading X and Y insets of the selection union in the parent's local padding box. It does not inspect right or bottom, bucket to four-pixel increments, or add padding at the root. Wrap always uses zero padding.
- The analyzer also returns rounded synthetic child rectangles. Main size is child sizes plus gap and twice main padding; cross size is the largest child plus twice cross padding.
- Existing absolute children remain absolute during direct Add, retain their placement, and clear stale Flex item data. Ordinary freeform children become flow children.
- An empty frame defaults to column, start alignment, gap 16, and padding 16. A wider-than-tall empty frame starts as a row with centered cross alignment.
- Wrap groups selected siblings by parent and analyzes each group in tree order. When any selected child is flow, absolute selected children do not participate in choosing the wrapper insertion index; otherwise all selected children do. The wrapper inserts at the maximum eligible sibling index, which is Paper's exact highest-selected-sibling rule.
- Wrap creates a non-clipping Frame, uses fresh stable order keys across its full child range, reparents in analyzer spatial order, clears absolute placement on every wrapped child, and applies the precomputed Flex plan without a second reorder. Every group is part of one semantic transaction and the new wrappers become the selection.
- An all-absolute group creates an absolute wrapper. Wrapper placement preserves the average of the original child AABB centers minus the average of the analyzer's synthetic child-rectangle centers. This is centroid preservation, not union-bounds-center preservation.
- Remove snapshots current flow children only, bakes Fit parent axes to current measured fixed pixels, changes the parent to freeform, clears Flex/Grid distribution, gap, axis padding overrides, and tracks, then restores former flow children at their exact measured parent-local positions. Authored base padding, margin, and overflow remain intact. Existing absolute children are untouched. Remove has no unsupported or cannot-reproduce branch when the current measurement is available.

### Child behavior

- Flow children disable X and Y. Absolute children expose position and pin controls.
- Before changing layout family, Paper snapshots every non-fixed axis intent, measured size, prior freeform-or-flow family, and whether an intrinsic text node is multiline. Multiline means measured height divided by resolved line height is greater than 1.5.

### MIME precedence

1. Plain text recognized as SVG becomes a synthetic `pasted.svg` and wins over image files.
2. Every `image/*` file is considered.
3. HTML is checked for the versioned Design editor payload, validated temporary-tree payloads, supported Figma markers, then supported Paper-style markers.
4. Plain text that is valid supported HTML enters the HTML importer.
5. Ordinary rich HTML is flattened to text. Otherwise plain text is inserted.
6. Unsupported clipboard data is ignored with an observable diagnostic.

### Format and security behavior

- Raster support includes PNG, JPEG, WebP, GIF, and AVIF. HEIC and HEIF convert to JPEG at quality 0.92. BMP and TIFF remain decoder-dependent and must be reported honestly.
- SVG import sanitizes with an SVG profile, removes scripts, iframes, event handlers, metadata, hidden empty elements, and unsafe external references, remaps IDs, and preserves supported shapes, paths, text, images, gradients, filters, and use references.
- Multiple images import concurrently and partial success is allowed.
- Limits cover per-file bytes, aggregate bytes, decoded pixels, dimensions, SVG or HTML node count, nesting depth, embedded payload size, and replacement count.
- Copy and cut do not intercept an active input, textarea, select, or contenteditable selection.
- Cut deletes only after copy succeeds and edit permission is still valid.
